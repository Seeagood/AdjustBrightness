亮度同步改为以显示器当前真实亮度为唯一来源，修复「软件调 20 → 移动中心改 30 → 退出再启动又变回 20」的问题。

- 启动时读取显示器当前真实亮度并沿用，不再用记录值把屏幕改回旧亮度；首次运行、重装、在系统里改过亮度，都以真实值为准。
- 运行中每 750ms 回读一次，发现外部改动（移动中心、系统设置、显示器按键、其它工具）立即更新界面、同步电源方案并保存；退出时也统一保存。
- 电源方案写入改为幂等：交流 / 直流亮度值已一致时不再重复写入，避免外部改动时反复重设电源方案。
- 修复 0% 语义：下发最低档后回读硬件真实下限（本机为 5）并持久化为 `hwFloor`，界面稳定显示 0%，重启后仍是 0%（此前会显示成 5%）。
- `config.ini` 新增 `[state] hwFloor`，记录实测到的硬件最低值。
- 安装包版本号同步为 1.0.3。

## 附件

- `AdjustBrightness.exe` — 免安装单文件（MSVC /MT 静态链接，无运行时依赖）
- `AdjustBrightnessSetup.exe` — 安装版，装到 `%LOCALAPPDATA%\AdjustBrightness`，不弹 UAC，覆盖安装前自动结束旧实例

## 系统要求

Windows 10 1809+ / Windows 11 x64；显示器需支持亮度控制（内置屏或支持 DDC/CI 亮度的外接显示器）。不支持时面板整体置灰。

可直接覆盖安装，或用免安装版替换旧文件；首次启动会沿用屏幕当前亮度，并自动生成 `[state] hwFloor`。
