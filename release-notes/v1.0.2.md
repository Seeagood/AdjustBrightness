新增「关于」面板与重新设计的自定义档位弹框，并修复卸载重装后首次启动亮度被强制改成默认值的问题。

- 新增「关于」面板：点左上角标题（太阳图标 +「内置显示器」）弹出，显示版本号与 GitHub 地址，点地址直接打开浏览器。
- 自定义档位弹框重新设计：5 列 × 2 行共 10 个输入框；标题栏右侧增加「最大值 50 / 100」选项，切换后按上限重填默认档位（50 → 5,10…50；100 → 10,20…100）。
- 0 档改为主面板内置，不再需要单独定义；主面板固定显示 0 + 最多 10 个自定义档位，共 11 个按钮。
- 保存自定义档位时仍自动升序排序并去重；输入超出范围会标红输入框并保留错误提示；点弹框外部即可关闭（只关弹框，主面板保持显示）。
- 修复：卸载后重装，首次启动不再把亮度改成 50%，而是沿用屏幕当前亮度并记为「上次亮度」。
- 安装包版本号同步为 1.0.2。

## 附件

- `AdjustBrightness.exe` — 免安装单文件（MSVC /MT 静态链接，无运行时依赖）
- `AdjustBrightnessSetup.exe` — 安装版，装到 `%LOCALAPPDATA%\AdjustBrightness`，不弹 UAC，覆盖安装前自动结束旧实例

## 系统要求

Windows 10 1809+ / Windows 11 x64；显示器需支持亮度控制（内置屏或支持 DDC/CI 亮度的外接显示器）。不支持时面板整体置灰。

## 升级说明

可直接覆盖安装，或用免安装版替换旧文件；`config.ini` 中的 `[presets] max` / `list` 会被保留。
