修复睡眠唤醒后亮度被系统改回旧值的问题（例如设置 20%，唤醒后变回 50%）。

- 根因：`WmiSetBrightness` / `SetMonitorBrightness` 只改显示器面板，没有改 Windows 电源方案里的「显示器亮度」，唤醒、重启、插拔电源时系统会按电源方案里的旧值重新下发亮度。
- 每次提交亮度（快捷档位、菜单、拖动松手、启动恢复）都会同步写入当前用户级电源方案的交流 / 直流亮度值，让界面、显示器面板、系统三方保持一致。
- 睡眠唤醒后再补写一次并复查，作为兜底。
- 只写当前用户级电源方案的亮度项，不需要管理员权限，也不改动电源方案的其它设置。
- 安装包版本号同步为 1.0.1。

## 附件

- `AdjustBrightness.exe` — 免安装单文件（MSVC /MT 静态链接，无运行时依赖）
- `AdjustBrightnessSetup.exe` — 安装版，装到 `%LOCALAPPDATA%\AdjustBrightness`，不弹 UAC，覆盖安装前自动结束旧实例

## 系统要求

Windows 10 1809+ / Windows 11 x64；显示器需支持亮度控制（内置屏或支持 DDC/CI 亮度的外接显示器）。不支持时面板整体置灰。

## 升级说明

可直接覆盖安装，或用免安装版替换旧文件；配置沿用程序目录下的 `config.ini`。建议安装后随意调一次亮度，让电源方案同步写入当前值。
