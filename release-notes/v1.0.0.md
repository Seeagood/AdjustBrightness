首个公开版本。

- 托盘常驻：左键切换面板显示/隐藏，右键菜单（打开、快捷档位、开机自启、退出）
- 亮度滑块 0–100，竖条控制柄整根可拖，0/25/50/75/100 刻度
- 快捷档位 + 自定义档位（3 列 11 项，升序去重，点弹框外部自动关闭）
- 开机自启、深浅色主题跟随系统、Per-Monitor V2 DPI 适配
- 单实例运行，面板默认贴屏幕右下角，退出重启重新贴右下角
- 配置文件只写程序目录的 config.ini，唯一的注册表项是开机自启（HKCU Run）

## 附件

- `AdjustBrightness.exe` — 免安装单文件（MSVC /MT 静态链接，无运行时依赖）
- `AdjustBrightnessSetup.exe` — 安装版，装到 `%LOCALAPPDATA%\AdjustBrightness`，不弹 UAC，覆盖安装前自动结束旧实例

## 系统要求

Windows 10 1809+ / Windows 11 x64；显示器需支持亮度控制（内置屏或支持 DDC/CI 的外接显示器）。不支持时面板整体置灰。
